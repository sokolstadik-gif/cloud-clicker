# Cloud Clicker — Telegram Mini App + Flask

Мобильная браузерная tap-to-earn игра: нажимай на облако, собирай **Cloudcoin**, покупай улучшения, выполняй цели по тапам и соревнуйся в общей таблице рекордов.

## Возможности

- Тёмная минималистичная тема и большая интерактивная кнопка-облако с надписью `CLICK`.
- Разделы: «Игра», «Эпохи», «Комбо», «Шифр», «Задания», «Новый год», «Подарки», «Бусты», «Рекорды», «Награды», «Статистика», «Магазин».
- Отдельное окно с создателем `@deIaywork` и ссылкой на Telegram.
- Промо-ссылка на Telegram-сообщество: https://t.me/+0wDVSjqHahAyNzMy.
- Cloudcoin как игровая валюта (внутри старой SQLite-схемы столбец `coins` сохранён ради совместимости).
- Нажатия с расходом энергии и автоматическим восстановлением.
- Карточки улучшений в категориях: облачные технологии, энергетика, исследования и инфраструктура.
- Прокачка силы нажатия, пассивного дохода и запаса энергии.
- Пассивный доход, в том числе пока игрок не на сайте (до 8 часов за один перерыв).
- Ежедневный бонус — 250 Cloudcoin один раз в сутки по UTC.
- Ежедневное комбо: выбери три карточки дня, улучши каждую и забери 3 000 Cloudcoin. Набор обновляется ежедневно.
- Ежедневный Morse-шифр: расшифруй слово дня и получи 2 000 Cloudcoin.
- Три ежедневных задания с отдельными наградами: тапать, покупать улучшения и забирать бонус входа.
- Два бустера: x2 к награде за тап на 30 секунд и мгновенное восстановление энергии.
- Награды за тап-милстоуны: 50 / 100 / 250 / 500 / 1 000 / 2 500 / 5 000 / 10 000 тапов.
- Награды выдаются по кнопке и доступны только один раз на аккаунт; проверка выполняется на сервере.
- Пять рейтингов TOP-10: заработанные монеты, тапы, приглашённые друзья, достижения и эпохи.
- Сохранение прогресса и наград на сервере в SQLite или PostgreSQL.
- Смена игрового имени.
- Telegram Mini App: идентификация по проверенному Telegram initData и привязка прогресса к Telegram ID.
- Встроенный магазин цифровой валюты за Telegram Stars (XTR), с проверкой pre-checkout и автоматическим начислением после webhook successful_payment.
- Кнопка полноэкранного режима (зависит от поддержки браузера).
- Экономика проверяется на сервере: клиент не может сам назначить себе баланс или получить награду повторно.

## Telegram Mini App и оплата Stars

### Важно про платежи
Внутри Telegram Mini Apps цифровые товары и игровая валюта должны продаваться за Telegram Stars (`XTR`). Встроенный магазин этого проекта использует Stars. Не принимай ручные переводы GRAM/TON за игровые Cloudcoin внутри Mini App.

### 1. Создай бота
1. Открой `@BotFather` и выполни `/newbot`.
2. Сохрани токен бота. Не публикуй его и не отправляй в чаты.
3. Размести приложение на публичном HTTPS-домене. Telegram Mini App не сможет корректно работать с локальным `127.0.0.1` или адресом локальной сети для внешних пользователей.
4. В `@BotFather` открой настройки созданного бота и настрой Mini App / Menu Button, указав HTTPS URL приложения. Для быстрого старта можно использовать `/setmenubutton`.

### 2. Настрой .env
Скопируй `.env.example` в `.env` и заполни:
- `BOT_TOKEN` — токен от BotFather.
- `TELEGRAM_WEBHOOK_SECRET` — длинный случайный секрет (буквы, цифры, `_` и `-`).
- `PUBLIC_BASE_URL` — публичный HTTPS URL, например `https://game.example.com`.
- `TELEGRAM_BOT_USERNAME` — username бота без `@`; нужен для Telegram Mini App реферальных ссылок.
- `DATABASE_URL` — необязательно; строка подключения PostgreSQL. Если не задана, используется SQLite.
- `SECRET_KEY` — длинный случайный секрет Flask.
- `REQUIRE_TELEGRAM_AUTH=1` — обязательно для публичного запуска.
- `COOKIE_SECURE=1` — для HTTPS.

### 3. Подключи Telegram webhook
На сервере из папки проекта выполни:

```bash
python set_webhook.py
```

Скрипт зарегистрирует `https://ТВОЙ-ДОМЕН/telegram/webhook`, включит обработку `pre_checkout_query` и `successful_payment`, а также попробует включить кнопку меню `Играть`. Команда `/start` ответит кнопкой открытия Mini App; `/terms` покажет условия покупок; `/support` — контакт поддержки.

### 4. Запусти приложение

```bash
waitress-serve --host=0.0.0.0 --port=5000 app:app
```

Настрой reverse proxy / хостинг так, чтобы публичный HTTPS URL направлялся на порт приложения. Для SQLite нужен постоянный диск. Для нескольких экземпляров приложения используй общую PostgreSQL-базу через `DATABASE_URL`; приложение поддерживает обе базы.

### Как работает вход
Фронтенд передаёт `Telegram.WebApp.initData` серверу в заголовке `X-Telegram-Init-Data`. Flask проверяет HMAC подпись бот-токеном и свежесть `auth_date`, затем связывает Telegram ID с существующим игровым профилем. Не используй `initDataUnsafe` для авторизации. Если в этом браузере уже был гостевой профиль и его cookie доступна внутри Telegram WebView, первый вход привяжет его к Telegram; иначе создастся новый профиль.

### Как работает магазин Stars
Кнопка магазина вызывает `createInvoiceLink` с валютой `XTR`. Telegram присылает `pre_checkout_query`, сервер сверяет владельца, сумму и payload, затем отвечает на pre-checkout. После `successful_payment` сервер начисляет Cloudcoin один раз, с защитой от повторного webhook. Настройка webhook обязательна, иначе оплаченные наборы не будут зачислены автоматически.

### Локальная разработка
Локальный режим без Telegram по-прежнему доступен при `REQUIRE_TELEGRAM_AUTH=0`. Но оплату Stars нельзя полноценно проверить только через локальную страницу; для теста Mini App нужен HTTPS адрес и созданный Telegram-бот.

## Требования

- Python 3.10 или новее.
- pip.
- Интернет нужен только для установки Flask и Waitress. В самой игре внешние библиотеки JS не используются.

## Запуск на Windows

1. Распакуй архив в отдельную папку.
2. Открой эту папку в проводнике.
3. В адресной строке папки напиши `cmd` и нажми Enter.
4. Создай виртуальное окружение:

   ```bat
   py -m venv .venv
   ```

5. Активируй его:

   ```bat
   .venv\\Scripts\\activate
   ```

6. Установи зависимости:

   ```bat
   pip install -r requirements.txt
   ```

7. Запусти игру:

   ```bat
   python app.py
   ```

8. Открой `http://127.0.0.1:5000`.

Можно также запустить `start_windows.bat` — он создаст окружение, установит зависимости и запустит игру.

## Запуск на macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Затем открой `http://127.0.0.1:5000`.

## Как открыть игру на телефоне в той же Wi-Fi сети

1. Запусти сервер на компьютере.
2. Узнай локальный IP компьютера (`ipconfig` на Windows).
3. На телефоне, подключённом к той же Wi-Fi сети, открой `http://IP-КОМПЬЮТЕРА:5000`.
4. Разреши Python принимать подключения в брандмауэре, если система спросит.

Компьютер должен оставаться включённым, пока телефон играет через него.

## Публикация в интернете

Чтобы игра была доступна друзьям из любой сети, размести проект на Python-хостинге или VPS с постоянным диском для `game.db`.

Для запуска через Waitress:

```bash
waitress-serve --host=0.0.0.0 --port=5000 app:app
```

Перед публичным запуском:

1. Установи длинный случайный `SECRET_KEY` в переменных окружения.
2. Включи HTTPS на хостинге и установи `COOKIE_SECURE=1`.
3. Убедись, что SQLite-файл `game.db` хранится на постоянном диске.
4. Не используй встроенный Flask-сервер как публичный production-сервер.

Пример для Linux/macOS:

```bash
export SECRET_KEY="вставь-длинный-случайный-секрет"
export COOKIE_SECURE=1
waitress-serve --host=0.0.0.0 --port=5000 app:app
```

## Где хранится прогресс

По умолчанию база `game.db` создаётся рядом с `app.py`; при заданном `DATABASE_URL` используется PostgreSQL. База хранит баланс и улучшения, прогресс эпох, энергию, календарные билеты, подарки, достижения, профили и награды. Идентификатор игрока хранится в подписанной cookie браузера. Поэтому очистка cookie, смена браузера или устройства создаёт нового игрока. Таблица рекордов общая для всех игроков на одном развёрнутом сайте.

Если обновляешь существующую установку, **не удаляй `game.db`**. Новые таблицы для комбо, шифров и заданий создадутся автоматически; дополнительные уровни улучшений добавятся миграцией, старые балансы и прогресс сохранятся.

Можно задать другой путь к базе через переменную окружения `DATABASE_PATH`.
